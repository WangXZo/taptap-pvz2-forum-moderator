# TapTap 论坛版主助手（植物大战僵尸2）

> 让 AI 帮忙盯 TapTap 论坛：每 10 分钟扫一次最新帖子，能答的自动答（带 TapTap 表情），
> 答不了的整理成清单交给版主。**社区里已经有人答过的，顺手把那份答案存进答疑库**，
> 下次同类问题就能自动回。

> ## 🔒 这个仓库是公开的 —— 提交前必读
>
> `qa/答疑库.md` 里的每个字全网可搜。**请勿写入**玩家昵称、UID、群号、QQ/微信、真实姓名。
> 需要指代某人时，用「社区玩家」；确需保留归属就**遮罩**：
>
> ```
> 玩家昵称示例  →  玩家****示例    保留首尾各 1~3 位，中间 * 补足到 8 位，保留字符 ≤50%

> ```
>
> 详细规则见 [SKILL.md 的「脱敏规范」](SKILL.md#-脱敏规范所有贡献者必读) 和 [qa/归档/脱敏记录.md](qa/归档/脱敏记录.md)。

## 它会做什么、不会做什么

**会**：

- 按发布时间抓取论坛最新 N 条（默认 8 条）
- 四类标记：⏳ 待回复 / ✅ 已回复 / ➖ 无需回复 / 🖐 需人工，输出 Markdown + CSV 报表
- 命中答疑库就**打开帖子 → 填正文 → 点选 TapTap 表情 → 发送**（带签名）
- 社区已有人答对的帖子 → **把那份答案沉淀进答疑库**，并在楼中楼夸一句
- 分享/进度/吐槽帖 → 去说句话（不输出信息，只互动）
- **玩家喊你**（签名/别名/「版主在吗」）→ 过去互动一次：敏感问题婉拒、问问题先查答疑库、其余按语气鼓励共情
- **多人协作按签名识别「回过没」** → 队友回过的不会重复回
- **版主管理任务**：检查**今天**的加好友帖（活动报名 + 讨论区两个子版块）
  → 命中「加好友/扩列/互赞好友/好友位/好友码/加群/加V」等**明确加好友意图**
  → 回固定文案（指向好友码集中贴）→ 再「论坛管理 → 移除」（自动点确认）
  → **每 2 分钟重新获取 + 按最新在前重排队列**，处理一直连着跑
  → 官方/版主/自己的帖直接跳过；活动组队（十月同游/组队）、活动邀请码、游戏功能里的「好友宝箱」一律放过
- 每天体检一次答疑库，剔除「携带自己标签」的脏条目

**不会**（有硬性安全阀）：

- 不碰充值/退款/封号/举报类内容（走人工）
- 不泄露内部信息（发送前过泄露自检，命中就拒发转人工）
- 不发没有把握的内容（库里没有 → 转人工，或按配置回一句婉拒）
- 表情插不上就**不发送**，绝不发出错误内容

## 三步跑起来

```bash
# 0) 装依赖（只需一次）
npm i -g @jackwener/opencli
#    并在 Chrome 装 opencli 扩展、登录 TapTap

# 1) 一键安装 + 自检
node scripts/install.mjs
#    它会检查环境、补全配置、建目录，然后跑一遍 doctor

# 2) 先看效果（不发送）
node scripts/watch.mjs --dry-run

# 3) 真跑
node scripts/watch.mjs
```

跑起来后看 `reports/questions.md`（人看）和 `reports/questions.csv`（Excel）。

### 常用命令

```bash
node scripts/doctor.mjs                # 自检：环境/配置/数据/脏条目
node scripts/whoami.mjs                # 拿自己的 user_id（填进 config.json）
node scripts/collect.mjs --dry-run     # 只跑一轮，不常驻、不发送
node scripts/qa-admin.mjs show         # 看答疑库有哪些条目
node scripts/qa-admin.mjs append ...   # 手工加一条问答
node scripts/qa-admin.mjs purge-tag    # 体检：有没有带自己标签的脏条目
node scripts/qa-admin.mjs purge-junk   # 体检：有没有广告/灌水条目
node scripts/post-admin.mjs recheck <id>   # 老帖子判定错了，重新判
node scripts/post-admin.mjs check-removed <id>  # 这帖还在不在版块里
node scripts/mod-task.mjs --dry-run    # 版主管理任务：只判定不移除
node scripts/mod-watch.mjs              # 版主管理任务常驻（检查每 2 分钟）
node scripts/report-gaps.mjs           # 生成「待补充问题清单」
node scripts/probe-dom.mjs summon      # 扫最新帖，找「玩家喊我们」的评论
```

## 答疑库：整个项目的核心

`qa/答疑库.md` 是**一个 Markdown 文件**，人人可读、人人可改。
机器人自动答什么、答得像不像人话，全看它。

- 格式与写法见 [qa/待补充问题.md](qa/待补充问题.md#问答格式)
- 正在补什么见 [qa/待补充问题.md](qa/待补充问题.md)（认领制，别撞车）
- 社区已答对的问题会被**自动沉淀**进来，不用手写

> ⚠️ **答疑库有两份**：仓库里的（人改，PR）和运行中的（守护进程自动沉淀）。
> 合并用 `node scripts/qa-sync.mjs --status` 看差异，
> `--to-repo` / `--to-runtime` 合并，`--apply` 才写。
> **永远不要直接覆盖** —— 历史教训见 [docs/方案.md](docs/方案.md)。

## 回复长什么样

**答一个问题**（答案来自答疑库，外面套不同说法）：

```
说白了，钻石主力就靠签到和每日任务先领满；植物探险、碎片挑战每天清掉。
攒起来不算慢。

「版主助手-小鲸鱼」
```

**夸一个答题好的玩家**（楼中楼）：

```
玩家B：困难6用机枪加冰车就行，我40级通关了
  └ 我们：哇~B大佬，牛逼 「版主助手-小鲸鱼」[表情_星星眼]
```

**分享帖说句话**：

```
宫一，宫二终于够币兑换1800了。
  └ 我们：大佬，好肝啊[表情_点赞]
```

口吻规范：短句、口语、可以调侃；**每类模板 ≥15 套**，而且最近用过的说法会主动避开 ——
玩家是会把版主所有回复翻一遍的。

## 怎么部署成常驻

Windows 上做不了系统服务（服务跑在 Session 0，看不到桌面 Chrome），
所以用**计划任务 + 登录时启动**：

```powershell
node scripts\schedule.ps1 -Action install
node scripts\schedule.ps1 -Action doctor
```

代价：机器得保持登录（锁屏可以，注销/关机不行）。详见 [references/ops.md](references/ops.md)。

## 多人协作须知

| 事实 | 后果 |
|---|---|
| 每个人的 `data/state.json` 独立 | A 回过哪些帖 B 不知道 → **同一问题可能被多人各回一遍** |
| `myUserId` 各不相同 | 互相判断不出「我已回过」（**现在靠签名兜住**：签名结尾的回复一律算「我们回过」） |
| 答疑库共享一份（仓库） | 答案口径一致 —— 这正是要共建它的原因 |

**结论：能多人用，但只能有一个账号开自动回复**，其他人用 `--no-reply` 只采集出报表。

> 版主管理任务（移除加好友帖）是**不可逆的版主动作**，多人同时开容易重复动同一帖 ——
> 建议只让一个账号开 `modTasks.enabled`。

## 已知限制

- **必须有桌面会话**：回复靠操作已登录的真实 Chrome
- **接口有阿里云 WAF**：探测太密会封 IP（实测 >25 分钟不恢复）。默认 10 分钟一轮，别改小
- **TapTap 官方 CLI 是只读的**：回复只能靠浏览器自动化，没有官方写接口
- **表情必须点选**：直接输入 `[表情_开心]` 只会变成纯文本
