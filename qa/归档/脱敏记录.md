# 脱敏记录（公开仓库发布前做的处理）

> 原则：**脱敏，不移除**。原文内容照旧保留在答疑库里，只把其中的个人标识**遮罩**掉。
> 处理日期：2026-10-28，发布到 GitHub 前。
>
> ⚠️ 本文件**故意不记录任何原始值** —— 写了原值就等于没脱敏。

## 一、遮罩规则

**保留首尾 1~3 位，中间用 `*` 替换，补足到统一 8 位；保留字符不超过 50%。**

| 原文长度 | 处理 | 例子 |
|---|---|---|
| ≥ 6 字 | 首 2 + `****` + 尾 2 = 8 位（保留 50%） | `首首****尾尾` |
| 2~5 字 | 首 1 + `******` + 尾 1 = 8 位（保留 25%） | `首******尾` |
| 1 字 | 全遮 | `********` |

**为什么统一 8 位**：`*` 的个数如果不统一，就等于把原文长度漏出去了。

## 二、被遮罩的对象

| 类型 | 处理方式 | 落点 |
|---|---|---|
| 版主本人的游戏昵称 | 遮罩 | 答疑库 / 归档 / 文档示例 |
| 版主本人的 TapTap user_id | 遮罩 | `scripts/config.json` |
| 社区玩家昵称 | 遮罩 | 答疑库 / 归档 |
| 玩家提问里的 UID 长串 | 遮罩 | 答疑库 / 待补充清单 |

## 三、换成假值（不是遮罩）的两类

| 场景 | 处理 | 原因 |
|---|---|---|
| **规则示例 / 测试数据** | 换成明显假的 `1234567890`、`99999` | 遮罩值带 `*`，就不再是「纯数字 ID」，示例与测试失去意义 |
| **运行时必填项** | `config.json` 的 `myUserId` 遮罩存储，但**跑前必须换成真值** | `doctor.mjs` 会拦截含 `*` 的值 |

## 四、保留的（不构成个人信息）

| 内容 | 为什么保留 |
|---|---|
| `- 来源：https://www.taptap.cn/moment/...` | 论坛公开帖链接，是答案的可追溯来源；不含账号标识 |
| `- 摘自：版主` / `社区玩家` / `答疑智多星` / `影响力UP` | 角色与徽章，不是昵称 |
| 游戏内数值、关卡名、植物名 | 事实内容，必须保留 |
| GitHub 账号名（`LICENSE` / `package.json`） | 公开仓库的 owner 信息，必然可见 |

## 五、复查

```bash
node scripts/doctor.mjs                  # 1. config 的 myUserId 是否还是遮罩值
node scripts/qa-admin.mjs purge-tag      # 2. 答疑库有没有带自己标签的脏条目
node scripts/test-question.mjs           # 3~9. 七套测试
```

全仓 grep（把关键词换成你知道的昵称/ID）：

```bash
grep -rniE '你的昵称|你的UID|[0-9]{9,11}' . --exclude-dir=.git
```

## 六、给贡献者的话

往 `qa/答疑库.md` 加问答时：

- ❌ 不写玩家昵称、UID、群号、QQ/微信
- ❌ 不写自己的真实姓名、所在地、联系方式
- ✅ 需要指代某人时，用「社区玩家」；确需保留归属就**遮罩**（`依******梦`）
- ✅ **来源链接要留** —— 那是可追溯性，不是个人信息

> 写进昵称，等于把那位好心答题的玩家挂进搜索引擎。
> 他只是回答了一个问题，不该承担这个。
