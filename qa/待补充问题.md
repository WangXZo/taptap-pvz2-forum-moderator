# 待补充问题清单（认领这个）

> 这份清单是**协作的核心**：一个人补太慢，所以把它摊开给所有人认领。
> 数据来源：守护进程跑出来的「没命中答疑库」的真实提问（`node scripts/report-gaps.mjs` 可随时刷新）。
> 更新日期：2026-10-28（答疑库 23 条）

## 怎么用这份清单

1. 挑一条**你答得上来**的（下面「待补充」区）
2. 在下面「我的认领」区写一行：`> @你的GitHub名 已认领 2026-10-28`，并写上你的答案要点
3. 按 [问答格式](#问答格式) 往 `qa/答疑库.md` 加一条，提交 PR
4. PR 描述里写清楚「补的是清单第几条」，方便维护者核对

> 不确定答案就**别认领** —— 宁可晚点补，也不要写错答案进库。
> 写错的答案会被自动回复出去，比不回答更糟。

## 问答格式

往 `qa/答疑库.md` 里加一条，**照抄这个格式**：

```markdown
## 问：玩家会怎么问这件事
- 关键词：关卡打不过, 卡关怎么办, 过不去, 卡在, 通关不了
- 版本：通用
---
先分清是阶数问题还是输出问题：阶数不够就去刷碎片升主力；输出不够就补单体爆发的植物。
在帖子里附上关卡号和阵容截图，看得更准。
```

### 三条硬要求

| # | 要求 | 反例 |
|---|---|---|
| 1 | **关键词写玩家的口语**，把各种问法都列上 | ❌ `关键词：关卡, 战斗` → ✅ `关键词：关卡打不过, 卡关怎么办, 过不去, 卡在几关` |
| 2 | **答案用玩家口气写**，短句、口语，可以调侃 | ❌「钻石主要靠以下几个稳定来源：1.每天签到 2.植物探险」→ ✅「钻石就靠签到和每日任务先领满，植物探险每天清掉」 |
| 3 | **事实必须准**。数字、名称、机制不能编 | ❌「大概 15% 左右吧」→ ✅「15%」或直接不写 |

### 不要写进去的

- 活动编号 / UID（`33****16` 这类，过期就废）
- 自己的签名「版主助手-小鲸鱼」—— 脚本会自动加（`qa-admin purge-tag` 会清掉带签名的条目）
- 「客服/找官方/私信/加群」这类引流话术（会被泄露自检拦下）
- 充值、退款、封号、举报类内容 → 这些走人工，不进自动答疑库
