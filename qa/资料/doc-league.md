## 名词澄清（最容易混的地方）

| 玩家说法 | 实际是什么 |
|---|---|
| **超 Z / 超 z 联赛 / 超级联赛** | **模式名** —— Arena（竞技场），旧称 Battlez |
| **钢铁联赛 / 青铜联赛 / 白银联赛 / 黄金联赛 / 翡翠联赛** | **段位名** —— 都指同一个模式，只是段位不同 |

> 所以「钢铁联赛」不是另一个模式，是**超 Z 联赛的起始段位**。
> 玩家说「打联赛」= 打超 Z。

## 段位（从低到高）

```
钢铁 → 青铜 → 白银 → 黄金 → 翡翠
```

| 段位 | 僵尸强度（社区口径） |
|---|---|
| **钢铁**（起始） | 不刷阶时 1~2 阶僵尸 |
| **青铜** | 最高 4 阶（含 4 阶巨人） |
| **白银** | 最高 6 阶（含 6 阶巨人） |
| **黄金** | 最高 7 阶 |
| **翡翠**（最高） | 最高 |

> 段位越高，僵尸数量越多、血量越高，难度递增。
> 另外**不同植物有联赛等级限制**。

## 赛季与升降级

| 项目 | 规则 |
|---|---|
| 小赛季 | **7 天**一轮，组内按分数排名 |
| 大赛季 | **42 天**（6 周 = 5 周比赛 + 1 周结算） |
| 晋级 | 小组**前三名**升一段 |
| 降级 | 小组**后三名**降一段（钢铁段位最后一名不降） |
| 重置 | 大赛季结束后**所有人回到钢铁** |
| 积分 | 赢一场 +5 分，输一场 +1 分 |

## 分数异常怎么判断（反外挂）

钢铁/超 Z 的分数不是无限的 —— **僵尸数量有限，能打出的最高分就有上限**。

| 现象 | 判断 |
|---|---|
| 分数**超过理论上限** | 可以视为**外挂** |
| 分数**个位不是 0** | 正常玩家拿分个位都是 0，末位非 0 要留意 |
| **万位和千位同时是 0**（形如 `??0000`） | 基本可以断定**外挂** |
| 分数异常但不符合上面特征 | 可能是**官方机器人** |

> 注意：「**追分机器人**」指的是**超 Z 里**的机器人，不在追击模式里。
