## 分数异常怎么判断（重要）

钢铁联赛的分数不是无限的 —— **僵尸数量有限，能打出的最高分就有上限**。

| 现象 | 判断 |
|---|---|
| 分数**超过理论上限** | 可以视为**外挂** |
| 分数末位**不是 0**（个位非 0） | 正常玩家拿分**个位都是 0**，末位非 0 要留意 |
| **万位和千位同时是 0**（形如 `??0000`） | 基本可以断定**外挂** |
| 分数异常但不符合上面外挂特征 | 可能是**官方机器人** |

> 判据来源：正常玩家拿分的规律是「个位为 0，最高能到万位」，
> 所以万位千位同时为 0 是不可能出现的组合。
