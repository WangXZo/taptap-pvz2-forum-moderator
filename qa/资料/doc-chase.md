## 定位

追击是拼**分数/速度**的模式。和无限不同：无尽拼活得久，追击拼打得快、分打高。

## 关卡结构（「打追 5」是什么意思）

追击共 **5 个关卡**：

| 关卡 | 难度数 | 说明 |
|---|---|---|
| 追击 1 ~ 4 | 每个 **3 种难度** | |
| **追击 5** | 只有 **2 种难度** | 玩家说「打追 5」= 打**第 5 个关卡** |
| BOSS 关 | **3 种难度** | 独立于上面 5 关 |

> 所以「打追 5」「追 5」都是指**第 5 关**，不是指分数。

## 主力植物

| 植物 | 作用 |
|---|---|
| **牛蒡家族** | 追击主力，社区说「提牛蒡家族打追 5」 |
| **菜问** | 大招能聚怪，新人打追击用得上 |
| **塔黄** | 升 5 在追击有点用（但也只是"有点用"） |
| **机枪 / 超级机枪** | 传送带关能用（双十一可以买） |

## 神器（这块很杂）

追击要的神器**很杂**，不是一套通用：

| 神器 | 用途 |
|---|---|
| **葫芦** | 追击能用；两边（无尽/追击）都能用 |
| **保龄球** | 同上，两边都能用 |
| **进化 + 退化** | 需要有 |
| **醒狮令** | 需要有 |
| **魔豆** | 需要有 |
| **摇滚街机** | 需要有 |

> 社区原话：「说不准哪天大佬开发个什么冷门神器提个几分，就得买了」——
> 也就是说追击的神器配置是**跟着版本和大佬开发走的**，别当固定答案背。

## 分数与对手

**「追分机器人」在超 z 里，不在追击。** 别把两个模式搞混。

追击里**应该有挂**（社区判断），遇到分数异常可以往这个方向想。

## 难度

追击难度**按期变化**，有的期给得明显偏高（社区反馈过「第一遍 135，这期难度有点高」）。
打不动先确认是不是当期本身就难，不一定是自己配置问题。

## 任务相关

追击的**僵王关**可以完成任务（如「这个狗比任务真恶心」那条问的就是任务怎么完成）。
