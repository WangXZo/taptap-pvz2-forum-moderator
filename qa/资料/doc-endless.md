## 开启时间

无尽**每周四中午 12 点**开启。

按钮是灰的、打不了 → 先看是不是没到时间，或者是不是没更新版本。

## 类型：每周轮换（固定顺序）

无尽的世界主题**每周轮换**，顺序固定：

```
埃及 → 海盗 → 西部 → 功夫 → 未来 → 黑暗 → 沙滩 → 冰河 → 天空
     → 失落 → 摇滚 → 恐龙 → 摩登 → 蒸汽 → 复兴 → 童话 → 地宫
```

**已知的实际排期**（从 2026-11-12 起，每周三推进）：

| 日期 | 无尽世界 |
|---|---|
| 2026-11-12 | 恐龙 |
| 2026-11-19 | 摩登 |
| 2026-11-26 | 蒸汽 |
| 之后 | 按上面的顺序依次往后推 |

> 想算后面是哪一期：从已知那期开始，沿顺序往后数。
> 例：11-26 是蒸汽 → 12-03 复兴 → 12-10 童话 → 12-17 地宫 → 之后回到埃及。

## 核心思路：靠机制斩杀，不靠堆输出

无尽后期基本都是**靠机制斩杀十阶巨人僵尸**，不是拼伤害。

具体做法就是「甜甜魔甘甘」那套（甜薯聚怪 → 魔音甜菜击飞浮空 → 飓风甘蓝吹飞击杀），
详见 `doc-glossary-phrases`。这套能打所有阶级、各体型的**普通僵尸**（含 10 阶），
但**打不了精英僵尸和 boss 僵尸**。

所以后期阵容的分工是：
- 清普通怪（含十阶巨人）→ 走机制（甜甜魔甘甘）
- 打 boss → 才需要输出型植物（如电大 / 电流超级机枪豌豆）

## 一豆三旗

| 说法 | 含义 |
|---|---|
| **一豆三旗** | 用**一个能量豆**，点击植物开大招，**直接完成 3 个「旗帜波」的多波僵尸**，通过关卡 |

**关键：不是 3 波僵尸，是 3 个旗帜波。**

一个**旗帜波**（关卡里带旗帜标记的节点）本身就包含**很多波僵尸** ——
所以一次开大推进的僵尸波数**远不止 3 波**。

> 所以「一豆三旗」的强度在于：拿一次大招换掉 3 个旗帜波的全部内容，直接把关卡推过去。
> 这也是为什么无尽里保龄球这类神器配「一豆三旗」很关键。

## 阵容方向（社区常见说法）

| 阵容 / 打法 | 适用情况 |
|---|---|
| **桑葚阵** | 没氪新一代无尽植物（球果、塔黄等）时的稳妥选择：不容易破阵、不太吃操作、偏挂机 |
| **塔黄阵** | 神器直接上「保龄球」（一豆三旗靠它）；5 阶心叶兰配塔黄二吸能减少动画、过波更顺 |
| **蛇皮果** | 处理中小型僵尸的性价比之王；1 阶无装扮就能用；有紫手套后完爆鸭梨 |
| **毁灭菇** | 想让无尽更快可以考虑 |
| **龙草 + 全息** | 龙草前面补一排全息 |
| **大嘴 / 龙草** | 场外巨人要靠它们吸进场再处理 —— **鸭梨打不了场外巨人** |

## 塔黄卡波怎么解

「卡波」= 波次推进卡住、过波不顺畅。

- **塔黄空吸到最高再点下一波**，别提前开
- 摇滚无尽本身出怪量最大、街机不吃球果大招 —— 过波不流畅是**正常现象**，不是操作问题
- 实在卡就换个无尽打

## 各无尽的特点

| 无尽 | 特点 |
|---|---|
| **摇滚无尽** | 目前所有无尽里**巨人最多**的一个；街机不吃球果大招；出怪量最大 |
| **摩登无尽** | 苹果带紫手套；棱镜塔击杀随缘出豆，一关出一两个就够用 |
| **地宫无尽** | 有「大战地宫之主」玩法（新版本） |
| **恐龙无尽** | 容易破阵 |

蓝色植物五阶进阶的东西，**不是只能靠无尽**：

3. 其他活动也会出
4. 氪金活动也有

## 商店

### 商品内容更新（每 2 个月）

**每两个月**换一批商品，主要是**植物碎片和装扮碎片**。

金币、挂件碎片这类**通常不变**。

### 货架刷新（每天 + 手动）

| 方式 | 规则 |
|---|---|
| **自动刷新** | 每天 **0 点**自动刷一次，随机变更货架上的 **6 种**商品 |
| **手动刷新** | 花**无尽币**手动刷，消耗递增：**10 → 500**（越刷越贵） |

> 所以想蹲某个商品：等每天 0 点的自动刷新，别急着花币硬刷。
