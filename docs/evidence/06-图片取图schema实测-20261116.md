# 图片识别 S1 取图 · 实测记录（2026-11-16）

> 匿名 + X-UA 只读探针实测，确认取图 schema / 通道 / 下载，端到端验证。探针：work/probe-image-schema3.mjs、work/probe-download.mjs。

## 1. 关键结论（修正设计稿原假设）

| 项 | 原假设 | 实测结论 |
|---|---|---|
| 图片位置 | contents.json 图片节点 | **`moment.topic.footer_images[]`**（topic 帖 type=2 无 contents.json） |
| 取图请求 | 需 detail | **feed 层 list item 已带 footer_images，无需额外 detail** |
| 取图通道 | 必须登录态页面上下文 | **匿名 + `X-UA` 头即可**（之前 success=false 是漏 X-UA，非 WAF） |
| moment id | id | **`id_str`** |
| CDN 防盗链 | 需 Referer/UA | **无防盗链**，裸 GET 也 200 JPEG |

## 2. footer_images 完整 schema（实测）

```json
{
  "url": "https://img2-tc.tapimg.com/moment/etag/<hash>_<ts>.jpg/_tap_ugc.jpg",
  "medium_url": ".../_tap_ugc_m.jpg",
  "small_url": ".../_tap_ugc_s.jpg",
  "large_url": ".../_tap_ugc.jpg",
  "original_url": "https://img2-tc.tapimg.com/moment/etag/<hash>_<ts>.jpg",
  "original_format": "jpeg",
  "width": 2400, "height": 1080,
  "color": "0x8e8a67", "original_size": 1601663
}
```
- OCR/VLM 用 **original_url**（原图）；缩略用 small/medium。
- X-UA 常量（skill http.mjs L9）：`V=1&PN=WebApp&LANG=zh_CN&VN_CODE=102&VN=3.62.0&LOC=CN&PLT=PC&DS=Android&OS=Windows&OSV=10&DT=PC&CH=chrome`。

## 3. 端到端验证样本

- 帖：「一发出了紫手套，等后续大哥返场了」 id_str=871396454843813708。
- 取 feed → footer_images[0].original_url → 裸 GET 200 JPEG（875774 bytes，2400×1080）→ 可读。
- 内容（宿主多模态实读）：**活动页面**——「获得奖励」弹窗（紫手套碎片×15、钻石×334、紫色粉末×150）；右侧「狂欢嘉年华」活动（仅剩1天9时、可能获得的植物碎片×4）；左侧活动列表（木士响叮当/僵尸清除计划/小马存钱罐/狂欢嘉年华/定制团购）；顶部货币 4840 钻 / 3,128,228 金币。
- 样本图：[实测样本-活动页面-20261116.jpg](实测样本-活动页面-20261116.jpg)。
- **意义**：正是大哥强调的重点①活动页面（植物/奖励）；证明 VLM 可语义读懂活动奖励/植物/时间，数字可 OCR，图标可模板匹配。

## 4. 对设计稿的影响

- S1 大幅简化：extractImages 直接读 feed item 的 topic.footer_images，匿名+X-UA（复用 ttGet），CDN 裸 GET 下载。
- 无需登录态、无需额外 detail 请求、无防盗链处理 → S1 工作量下调。
