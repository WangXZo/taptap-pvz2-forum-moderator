# 提问判定规则（looksLikeQuestion）

> 代码位置：`scripts/lib/qa.mjs` 的 `looksLikeQuestion()`
> 回归用例：`scripts/test-question.mjs`（31 条，改规则前后各跑一次）

## 为什么需要它

论坛里混着三类帖：**真问题**（要回）、**攻略/分享/组队**（不用回）、**无效帖**（纯 ID、太短）。
判定错了有两个后果，方向相反：

| 判错方向 | 后果 |
|---|---|
| 把提问判成非提问 | **没人回**，提问者被晾着 —— 伤害更大 |
| 把非提问判成提问 | 多进一条「🖐 需人工处理」，版主扫一眼划走 —— 成本很低 |

所以原则是 **尽量回答问题**：模糊情况一律偏向「是提问」。

## 判定顺序（顺序本身就是逻辑，别调换）

```
输入标题
  │
  ├─ 0. 去掉 [表情_xxx] / [TapTap×xxx_yyy] 标记
  │     只剩标记 → 非提问
  │
  ├─ 1. 命中「明确非提问」→ 非提问          ← 必须最先判
  │     【攻略】【前瞻】【福利】… / 攻略 / 教程 / 分享 / 记录 / 吐槽 /
  │     公告 / 招募 / 加群 / 组队 / 满勤 / 兑换码 / 激活码 /
  │     码:XXXX / http(s)链接 / 兑换了 / 终于 / 集齐 / 毕业了 /
  │     打过了 / 通关了 / 白嫖到
  │
  ├─ 2. 命中「疑问/求助」→ 提问
  │     什么 / 怎么 / 怎样 / 咋 / 咋办 / 如何 / 为什么 / 为啥 /
  │     哪个 / 哪种 / 哪些 / 哪关 / 哪张 / 哪里 / 在哪 /
  │     多少 / 几个 / 几天 / 几次 / 多长 /
  │     能不能 / 可不可以 / 可以吗 / 行不行 / 有没有 / 有人帮 /
  │     是否 / 是不是 / 会不会 / 要不要 / 值不值 / 值得吗 /
  │     求推荐 / 推荐 / 求问 / 求教 / 求助 / 请问 / 问一下 /
  │     大佬 / 萌新 / 新手 / 急 / 在线等 / 返场 / ? / ？
  │
  ├─ 3. 纯字母数字（2219833926 / abc123456）→ 非提问
  │
  ├─ 4. 长度 < 6 且无疑问词（「天宫码」「塔黄」）→ 非提问
  │
  └─ 5. 其余模糊情况 → 提问（默认兜底）
```

### 为什么「非提问」必须排在「疑问词」前面

攻略帖正文里经常带疑问句：

```
【官方攻略】主线 未来世界篇-困难6攻略
这关怎么打，先放向日葵再放豌豆
```

标题含「攻略」但也有「怎么」。先判疑问词 → 攻略帖被判成提问，白回一条。
先判非提问标记 → 正确判为非提问。**这个顺序曾经反过，实测误判过。**

### 为什么「码」规则要限定在「码」字后面

早期用了 `[A-Z0-9]{8,}` 直接匹配长串字母数字，结果把

```
4353169611有人帮一下吗
```

当成兑换码判死了 —— 那其实是一串 UID 加一句求助。现在规则是 `码\s*[:：]?\s*[A-Za-z0-9]{4,}`，即「码」字后面才认。

### 为什么纯数字判定要排除中文

「买了塔黄无尽用什么不较好」里也有数字感，但含中文。`/^[A-Za-z0-9]+$/` 是**全串**锚定 + 中文会让它不匹配，所以不会被误杀。

## 三个历史 bug（都实测踩过，改动时别退回去）

| # | bug | 症状 | 修法 |
|---|---|---|---|
| 1 | 词表只有「为什么」，没有独立的「什么」 | 「买了塔黄无尽**用什么**不较好」漏判 → 该条被标 `no_need` 没人回 | 补「什么」「咋」「值得吗」等口语疑问词 |
| 2 | 先判疑问词、再判非提问标记 | 「【官方攻略】…困难6攻略」（正文含"怎么"）被判成提问 | 顺序对调，NOT_ASK 优先 |
| 3 | `no_need` 状态无条件复用 | 规则改了，旧帖仍沿用旧结论，永远不翻案 | 仅当**新判定也是** `no_need` 才复用；升级则采纳新判定并打 `[翻案]` 日志 |

bug 3 在 `scripts/collect.mjs`（状态复用逻辑），不在 `qa.mjs`。

## 改词表怎么改

1. **只加词，不动顺序**。顺序（NOT_ASK → ASK → ID → 长度 → 默认提问）是逻辑，改它必然引入误判。
2. **加词前先想反向影响**：加进 NOT_ASK 会漏回真问题；加进 ASK 只会多一条人工处理。
   → **拿不准就加进 ASK**（符合"尽量回答"原则）。
3. 改完 `node scripts/test-question.mjs`，31 条必须全过。
4. 新发现的真实误判案例，**补进 `test-question.mjs` 的 CASES**，别只改代码 —— 用例是给下一个人看的。
5. 词表是按词根匹配的（`什么` 会命中 `为什么` 之外的所有 `什么` 组合），加长词收益低，加口语短词收益高（「咋」「啥」「咋办」）。
