# TapTap 表情参考（PVZ2 论坛，实测导出）

> 导出时间：2026-10-26，面板第 1 组「标准表情」共 **61** 个（id 70~130）。
> 写法：回复文案里写 `[表情_开心]`，脚本会**模拟点选**插入（直接输入无效）。

## 怎么用

在 `qa/答疑库.md` 的回复正文里写：

```markdown
## 问：什么时候能拿到新植物
- 关键词：新植物, 解锁, 什么时候
---
新植物按版本节奏开放，进图签就能看到预告啦[表情_开心]
```

- 表情可放**句中或句尾**，脚本用光标定位精确插入（已实测双表情中间插入成功）
- 多个表情会**从后往前**插，避免位置偏移
- 表情名不在下表 → 该条自动转「🖐 需人工处理」，**绝不会发出错内容**
- 每次插入后会校验实际插入的 identifier，对不上就中止发送

## 其它分组（当前不支持）

面板还有 6 个联动游戏分组（洛克王国世界 / 王者荣耀 / 蛋仔等，id 246~520，identifier 形如
`[TapTap×洛克王国世界_耶]`）。

**不支持跨组点选** —— 实测跨组时 DOM ref 会错位，导致插入的是别的表情。
需要的话必须先在 `config.reply.emoji` 里显式放开并加校验，**不要直接改脚本**。

## 技术要点（改脚本前先读）

编辑器是 **tiptap/ProseMirror**，几个关键事实：

1. **直接输入 `[表情_xxx]` 只会变纯文本** —— 编辑器不认这个标识符
2. **必须点选**：点工具栏第 2 个按钮 → 面板里点具体表情 → 生成
   `<span data-type="tapEmoji" data-emoji-id="71" data-identifier="[表情_开心]" class="tap-emoji">`
3. **`fill` / `type` 对编辑器都是「整体替换」** —— 不能追加文字
   → 所以做法是：`fill` 填完整纯文字 → eval 定位光标 → 点选表情插到光标处
   → eval 只改 selection，不改内容
4. **`fill` 的 `verified` 字段对多行文本会误报 false**（它把段落换行算进差异）。
   实际内容是对的（`<p>a</p><p><br></p><p>b</p>` 三段结构）。
   → 所以脚本不用它的 `verified`，改为读 `innerText` 逐行比对关键片段
5. **面板按钮是 toggle**，盲点可能反而关掉面板 → 必须先查 `isPanelOpen` 再决定点不点
6. **跨分组点选会插错表情**（实测：想插"耶"，实际插进了"微笑"）
   → 只用第 1 组，插入后校验 identifier，对不上就中止发送

服务端落库格式（实测）：

```json
{"type":"tap_emoji","children":[{"text":"[表情_开心]"}],"info":{"id":71,"img":{...},"style":"inline"}}
```

`data-style` 有 `inline` / `default` 两种：标准表情组是 `inline`，联动组是 `default`。
